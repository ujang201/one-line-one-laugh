## The line

> My password manager just asked me to reset the password to my password manager, so now neither of us trusts me.

## How it works

`main.ts` builds the joke from two beats — a relatable setup and a twist
that turns the setup back on the speaker (the tool meant to remember
passwords for us ends up doubting us instead) — checks that the result is
a single line of 1–140 characters, and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (which runs TypeScript directly). The program
prints the line and writes it to `/output/entry.txt`.
